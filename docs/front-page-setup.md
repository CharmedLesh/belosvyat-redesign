# Статична головна та стрічка новин на `/news`

Тема містить окремий шаблон головної сторінки (`front-page.php`), але сам по собі
він не вмикається: WordPress показує його лише тоді, коли в «Налаштування →
Читання» вибрано **статичну сторінку**. Цей документ описує, що саме треба
зробити на бойовому сайті після викладання теми.

## Що змінюється

| До | Після |
|---|---|
| `/` — стрічка записів | `/` — головна: банер, «Про парк», рослини, тварини, анонс новин, ВІАР-тур |
| стрічки новин за окремою адресою немає | `/news/` — та сама стрічка з бічною панеллю та пагінацією |
| перший пункт меню «Головна» → `/` | той самий пункт «Новини» → `/news/` |

Повернутися на головну можна логотипом і назвою сайту в шапці — вони завжди
ведуть на `/`.

## Що робить скрипт, а що лишається вручну

| Дія | Скрипт | Вручну |
|---|---|---|
| Створити сторінки «Новини» (`news`) і «Головна» (`golovna`) | так | — |
| «Налаштування → Читання»: статична головна + сторінка записів | так | — |
| Перший пункт меню → посилання на сторінку «Новини» | так | — |
| Тексти розділів головної (Кастомайзер) | **ні** | так, за потреби |

## Варіант А — скриптом (потрібен доступ до консолі)

```
cd /шлях/до/wp-content/themes/belosvyat-redesign
php tools/front-page-migration.php
```

Скрипт **ідемпотентний**: його можна запускати повторно, він нічого не дублює.
З браузера він не працює — віддає 403.

Локально (Local by Flywheel, Windows) потрібен саме бінарник PHP 7.4 і php.ini
поточного запуску сайту. Ідентифікатор запуску (`ZqBHWOz5Q` у прикладі)
змінюється після перезапуску сайту, тож спершу подивіться, який він зараз:

```
ls "$APPDATA/Local/run"

"$APPDATA/Local/lightning-services/php-7.4.30+6/bin/win64/php.exe" \
  -c "$APPDATA/Local/run/<RUN_ID>/conf/php/php.ini" \
  tools/front-page-migration.php
```

Якщо взяти PHP 8.2 замість 7.4, `wp-load.php` завершиться помилкою «missing the
MySQL extension»: розширення лежать у теці 7.4.

Очікуваний вивід (адреси будуть бойові):

```
створено сторінку «Новини» (/news/)
створено сторінку «Головна» (/golovna/)
пункт меню #126 тепер веде на сторінку «Новини»

news=9125 (https://belosvyat.com.ua/news/)
home=9126 (https://belosvyat.com.ua/)
show_on_front=page page_on_front=9126 page_for_posts=9125
перший пункт меню: type=post_type object_id=9125 url=https://belosvyat.com.ua/news/
```

## Варіант Б — вручну в адмінці

1. **Сторінки → Додати нову** → назва **Новини**. У блоці посилання виправте
   слаг на **`news`** — плагін `rus-to-lat` за замовчуванням зробить `novini`.
   Опублікуйте. Вміст лишіть порожнім: сторінка потрібна лише як контейнер для
   стрічки записів.
2. **Сторінки → Додати нову** → назва **Головна**, слаг **`golovna`**, вміст
   порожній. Шаблон не вибирайте: тема застосує `front-page.php` сама.
3. **Налаштування → Читання** → «На головній сторінці показувати» =
   **Статичну сторінку**; «Головна сторінка» = **Головна**; «Сторінка записів» =
   **Новини**. Зберегти.
4. **Вигляд → Меню** → меню «навігація по сайту»:
   - видаліть перший пункт **Головна** (це «Довільне посилання»);
   - у лівій колонці розгорніть **Сторінки**, позначте **Новини**, натисніть
     «Додати до меню»;
   - перетягніть новий пункт на перше місце; у полі «Мітка навігації» має бути
     **Новини**;
   - Зберегти меню.

   *Чому саме видалити й додати заново, а не переписати адресу: старий пункт —
   довільне посилання з абсолютною адресою в базі. Пункт-сторінка бере адресу зі
   самої сторінки, тож переїзд домену чи зміна слага його не зламають.*
5. **Налаштування → Постійні посилання** → «Зберегти зміни» (скидання правил
   перезапису, щоб `/news/` відкривався одразу).

## Перебудова головного меню

Після переходу на статичну головну меню теж змінюється. Робить це другий
скрипт — `tools/menu-restructure.php` (теж ідемпотентний, теж лише з консолі):

```
php tools/menu-restructure.php
```

Він вимагає, щоб статична головна вже була налаштована (див. вище), бо бере ID
головної сторінки з «Налаштування → Читання».

Що саме змінюється:

| Було | Стало |
|---|---|
| — | **Головна** — новий перший пункт, веде на `/` |
| **Екоосвіта та рекреація** (випадайка з 4 підпунктами) | **Склад відділу екоосвіти та рекреації** — один пункт на `/sklad-viddilu-3/` |
| **Робота служби державної охорони** (у випадайці «Охорона ПЗФ») | прибрано |
| **Проект організації території парку** | прибрано |

Підпункти екоосвіти («Склад відділу», «Екотуристичні маршрути», «Напрями
роботи», «Правила поведінки на маршрутах») зникають разом із випадайкою —
самі сторінки лишаються в базі, з меню прибрано лише посилання на них.

Порядок пунктів після змін:

```
Головна · Новини · Наука ▾ · Склад відділу екоосвіти та рекреації ·
Охорона ПЗФ ▾ · Електроний квиток · ВІАР-ТУР
```

### Вручну в адмінці

**Вигляд → Меню**, меню «навігація по сайту»:

1. У лівій колонці `Сторінки` позначте **Головна** → «Додати до меню» →
   перетягніть на перше місце. У полі «Мітка навігації» лишіть **Головна**.
2. Розгорніть пункт **Екоосвіта та рекреація** (це «Довільне посилання») і
   натисніть «Вилучити». Далі в лівій колонці `Сторінки` позначте сторінку
   **Склад відділу** (слаг `sklad-viddilu-3`), додайте до меню, перетягніть на
   місце видаленої випадайки й у полі «Мітка навігації» впишіть
   **Склад відділу екоосвіти та рекреації**.
   *Разом із випадайкою зникнуть і її підпункти — так і треба.*
3. Розгорніть **Робота служби державної охорони** (у «Охорона ПЗФ») →
   «Вилучити».
4. Розгорніть **Проект організації території парку** → «Вилучити».
5. «Зберегти меню».

Мобільне меню окремо налаштовувати не треба: тема показує те саме меню й на
широких екранах, і під бургером.

## Тексти розділів головної

> Тексти головної зберігаються в опції `theme_mods_belosvyat-redesign`, **а не в
> записах чи сторінках**. Ні скрипт, ні експорт сторінок їх не перенесе.

Заповнювати їх на бою не обов'язково: заголовки розділів і написи на кнопках
мають значення за замовчуванням, а описи порожні — розділ просто покаже
заголовок, галерею та кнопку. Коли з'явиться готовий текст, впишіть його у
**Вигляд → Налаштувати → Головна сторінка**:

| Поле в Кастомайзері | Що це | Типове значення |
|---|---|---|
| Про парк: заголовок | заголовок першого розділу | `Про парк` |
| Про парк: текст | опис парку | *порожньо* |
| Рослини: заголовок | заголовок розділу з каруселлю флори | `Рослинний світ` |
| Рослини: текст | опис над каруселлю | *порожньо* |
| Рослини: напис на кнопці | кнопка веде на `/flora/` | `Докладніше про флору` |
| Тварини: заголовок | заголовок розділу з мозаїкою фауни | `Тваринний світ` |
| Тварини: текст | опис над каруселлю | *порожньо* |
| Тварини: напис на кнопці | кнопка веде на `/fauna/` | `Докладніше про фауну` |
| Новини: заголовок | заголовок анонсу новин | `Новини парку` |
| Новини: напис на кнопці | кнопка веде на `/news/` | `Усі новини` |
| ВІАР-тур: заголовок | заголовок розділу з панорамою | `ВІАР-тур парком` |
| ВІАР-тур: текст | опис над панорамою | *порожньо* |
| ВІАР-тур: адреса панорами | порожньо — береться з iframe сторінки «ВІАР-ТУР» | *порожньо* |

Банер (заголовок, підзаголовок, кнопка, фонове зображення) налаштовується там
само, у розділі **«Банер на головній»** — він тепер показується і на `/`, і на
`/news/`.

## Звідки беруться зображення

Головна не має власних копій галерей:

- карусель рослин — зображення сторінки **«Флора»** (`/flora/`);
- мозаїка тварин — блочна галерея сторінки **«Фауна»** (`/fauna/`): перші
  ~18 зображень, розкладені по панелях 2×2;
- панорама — перший `iframe` зі сторінки **«ВІАР-ТУР»** (`/viar-tur/`).

Отже, щоб оновити головну, достатньо відредагувати відповідну сторінку. Зібрана
розмітка кешується на 12 годин і скидається сама, щойно сторінку-джерело
збережуть заново.

## Перевірка після міграції

- `/` — банер, п'ять розділів, без бічної панелі; кнопки ведуть на `/flora/`,
  `/fauna/`, `/news/`;
- `/news/` — банер, заголовок «Новини», картки записів, бічна панель,
  пагінація внизу;
- пункт меню «Новини» підсвічений на `/news/`, а «Головна» — на `/`;
- у меню немає «Екоосвіта та рекреація» з підпунктами, «Робота служби державної
  охорони» та «Проект організації території парку»;
- `/flora/`, `/fauna/`, `/viar-tur/` виглядають як раніше;
- клік по зображенню в мозаїці на головній відкриває саме це зображення.

## Відкат

**Налаштування → Читання** → «На головній сторінці показувати» = «Ваші останні
записи». Пункт меню поверніть на довільне посилання `/` з міткою «Головна».
Сторінки `news` і `golovna` можна лишити — вони порожні й нікому не заважають.
