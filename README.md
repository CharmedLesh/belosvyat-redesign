# Білобережжя Святослава — тема WordPress

Класична (не блокова) тема для сайту національного природного парку
«Білобережжя Святослава». Замінює тему, згенеровану Artisteer у 2011 році.

## Структура

```
functions.php            завантажувач: підключає inc/*
theme.json               палітра, типографічна шкала, відступи, ширини макета
style.css                лише заголовок теми (стилі — в assets/css/main.css)

inc/setup.php            add_theme_support, меню, розміри зображень, назва сайту
inc/enqueue.php          підключення CSS/JS з версією за filemtime()
inc/widget-areas.php     10 областей віджетів + belosvyat_has_sidebar()
inc/nav-walker.php       Belosvyat_Nav_Walker — підменю з кнопкою та ARIA
inc/template-tags.php    мініатюри, метадані, пагінація, крихти, множина
inc/customizer.php       налаштування банера, головної сторінки й підвалу
inc/shortcodes.php       [year]
inc/legacy-content.php   анонси + обгортка таблиць для старого контенту
inc/gallery.php          карусель, мозаїка 3×3 і джерела зображень для головної

front-page.php                     головна: банер + п'ять розділів
template-parts/hero.php            банер головної та стрічки новин
template-parts/front/section-*.php розділи головної (про парк, флора, фауна, новини, тур)
template-parts/content/*.php       картка, запис, сторінка, «нічого не знайдено»

assets/css/main.css      усі стилі (16 секцій, див. коментар угорі файлу)
assets/js/navigation.js  меню, підменю, пошук, липка шапка, «нагору» — без jQuery
assets/js/gallery.js     карусель, мозаїка та перегляд зображень поверх сторінки

tools/front-page-migration.php     одноразове перемикання на статичну головну
tools/menu-restructure.php         одноразова перебудова головного меню
docs/front-page-setup.md           як увімкнути головну та /news на бою
docs/deploy.md                     як викласти тему на бій і відкотити
```

## Що успадковано від старої теми навмисно

Ці ідентифікатори збережені, бо до них уже прив'язані дані в базі:

| Ідентифікатор | Чому не можна змінювати |
| --- | --- |
| `primary-widget-area`, `secondary-widget-area`, `first-top-…` тощо (10 шт.) | у `sidebars_widgets` уже розкладені віджети |
| Розташування меню `primary-menu` | до нього прив'язане меню «навігація по сайту» |
| `onecolumn-page.php` + `Template Name: One Column` | сторінки зберігають ім'я файлу в `_wp_page_template` |
| Шорткод `[year]` | присутній у збереженому тексті підвалу |

Мініатюру записів навмисно шукаємо в три кроки (зображення запису → перше
вкладення → перший `<img>` у тексті): більшість записів 2012–2020 років не мають
«зображення запису», і без цього ланцюжка сітка карток була б порожня.

## Налаштування

- **Вигляд → Налаштувати → Банер на головній** — заголовок, підзаголовок, кнопка.
  Банер показується на головній та на сторінці новин.
- **Вигляд → Налаштувати → Головна сторінка** — заголовки й тексти розділів
  головної. Зображення туди підтягуються зі сторінок «Флора» та «Фауна»,
  новини — з останніх записів. Див. `docs/front-page-setup.md`.
- **Вигляд → Налаштувати → Зображення шапки** — фонове фото банера.
  Без нього банер показує градієнт у кольорах теми.
- **Вигляд → Налаштувати → Логотип** — логотип у шапці.
- **Вигляд → Налаштувати → Підвал** — текст унизу сторінки (підтримує `[year]`).

## Мова

Рядки інтерфейсу написані українською безпосередньо в коді й обгорнуті в
`__( …, 'belosvyat' )`. Файл перекладу не потрібен: сайт україномовний
(`WPLANG = uk`), а інші мови обслуговує плагін GTranslate.

Через відсутність `.mo` функція `_n()` застосувала б англійське правило множини,
тому для числівників використовується `belosvyat_plural()` з українським
правилом (1 матеріал / 2–4 матеріали / 5+ матеріалів).

## Вимоги

WordPress 6.0+, PHP 7.4+.
